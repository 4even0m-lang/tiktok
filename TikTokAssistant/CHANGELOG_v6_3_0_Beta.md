# Ven0m TikTok LIVE Assistant v6.3.0 Beta — Foundation

## تم تنفيذها في هذا الإصدار

- **تخزين قابل للتوزيع:** أصبح `settings.json` و`gift_catalog.json` في `%LOCALAPPDATA%\Ven0m` في Windows، بدل محاولة الكتابة في مجلد التثبيت. النقل من ملفات المجلد القديم يعمل دون الكتابة فوق بيانات المستخدم الموجودة.
- **العمل داخل EXE:** عند تجميع التطبيق بـ PyInstaller، عمليات Gift / Overlay تستدعي نفس ملف EXE باستخدام `--worker` بدل افتراض وجود ملفات Python منفصلة على قرص المستخدم.
- **Simulation Studio (Beta):** زر محاكاة من صفحة Overlay لتجربة هدية/متابعة/لايك/تعليق دون اتصال مباشر ببث TikTok. المحاكاة لا تعدّل إحصائيات الجلسة أو قوائم المتصدرين. قد تُشغّل تنبيهات Actions المربوطة بالأحداث إن وُجدت.
- **EventBus:** واجهة داخلية موحدة للأحداث لتسهيل إضافة اتصالات وتحليلات مستقبلًا، دون تغيير إعدادات المستخدم الحالية.
- **PlaybackCoordinator:** أساس برمجي مجرّب لطابور متعدد الشاشات يسمح بإشعار نشط واحد مع انتهاء أو مهلة؛ **لم يتم توصيله بعد بمشغل المتصفح الفعلي**.
- **التشخيص:** سجل أخطاء محلي محدود الدوران في `%LOCALAPPDATA%\Ven0m\logs\crash.log`، دون إرسال السجل إلى أي جهة تلقائيًا.
- **بناء Windows:** جمع الأصول اللازمة للتشغيل واختبار مُخصّص لـ EXE (يتطلب تشغيل GitHub Actions أو البناء على Windows)، مع التحقق من ملفات الهدايا ومسارات Overlay.

## ما زال قيد التطوير

- ربط Events بشاشات Overlay متعددة والإجبار الفعلي على منع تشغيل إشعارين معًا (**مخطط لـ 6.4**).
- Goal Overlays الاحترافية، تاج المتصدر الأول، خطوط Windows داخل محرر الإشعارات، Motion Timeline (**مخطط لـ 6.5 وما بعدها**).
- نظام تحديث تلقائي داخل التطبيق وSQLite وترحيل تاريخ الإصدارات (**ليست جاهزة في هذه النسخة**).

## اختبار هذه الحزمة

- تم تشغيل اختبارات Python المصدرية ونجحت 63/63 في بيئة إنشاء الحزمة.
- لم يتم إنشاء EXE Windows ولا إجراء اختبار فعلي للواجهة/البث من هذا النظام؛ البناء واختباره على Windows خطوة منفصلة.
- هذه نسخة تجريبية: احتفظ بنسخة احتياطية من الإعدادات والوسائط قبل ترقية نسخة قديمة.
